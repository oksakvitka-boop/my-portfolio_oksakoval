# Creative portfolio — перший макет

Це демонстраційний персональний сайт-портфоліо з **трьома основними розділами**:

1. **Graphic Design** — 8 тематичних проєктів. Кожна картка відкриває велику добірку з 4 композицій, як у Behance.
2. **AI Video** — сітка вертикальних прев'ю у співвідношенні **9:16**. Реальні MP4 поки не додані.
3. **Blender 3D** — 6 категорій 3D-робіт з відкриттям окремих добірок.

Усі картинки в першому прототипі — **демонстраційні CSS-композиції**, не чужі роботи. Це лише приклади дизайну до завантаження власних матеріалів.

## Як відкрити

Завантажте файл `index.html` та відкрийте його у браузері подвійним кліком. Сайт працює локально без додаткових програм.

## Як опублікувати безкоштовно

- Netlify → Add new project → Import existing project → GitHub → цей репозиторій.
- У налаштуваннях статичного сайту: **Build command** залишити порожнім, **Publish directory**: `.` (корінь репозиторію).
- Наступні зміни в `main` автоматично публікуватимуться на Netlify після підключення.

## Як редагувати

Всі стилі, дані та скрипти зараз збережені в одному `index.html` для зручної роботи з ChatGPT.
У кінці HTML є три масиви: `projects`, `videos`, `three`. Їх пізніше замінимо на справжні фото, банери та відеофайли.
Після узгодження макета додамо файли в `assets/`, замінимо демонстраційні графічні композиції на реальні медіа та додамо персональні дані.

**Увага:** посилання на GitHub показує код. Для перегляду як сайту відкрийте `index.html` локально або публічну адресу Netlify після розгортання.
