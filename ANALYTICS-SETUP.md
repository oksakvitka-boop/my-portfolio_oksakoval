# Analytics setup
The analytics module is inactive until the owner supplies a real GA4 Web stream measurement ID (G-...). Set ID in portfolio-analytics.js. Enable GA4 custom event dimensions project_name, project_type, video_title, contact_channel; optional custom metric video_percent. Review enhanced measurement to avoid duplicate events and form data. Test consent, page_view, project_open, portfolio_video_start/progress/complete and contact_click in Realtime. Native HTML videos are supported; embedded Vimeo playback is not. No full IP addresses or identities are collected by the module. Data is limited to consenting visitors after activation; ad blockers may reduce totals. Connect GA4 to Windsor.ai for reporting in ChatGPT.
